# Open Study Materials Research

An research skill for AI agents (Codex, Claude Code, Open Code and other Agent Skills runtimes). It helps an agent find and evaluate open study materials, including textbooks, lecture notes, courses, and exercises. The agent checks sources, assesses relevance, and distinguishes freely accessible materials from openly licensed resources.
