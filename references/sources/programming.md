# Programming Sources

Starting points for programming study, grouped by topic.

## Programming fundamentals

### Harvard — CS50x
- URL: https://cs50.harvard.edu/x/
- Materials: Lectures and programming exercises.
- Useful for: A broad introduction to computer science and programming.
- Access: Free learning materials and exercises.
  CS50's own completion certificate is free;
  edX verified certificates cost extra.
- Selection: Check the current syllabus and workload against
  the learner's background.

### MIT — Introduction to Computer Science and Programming Using Python
- URL: https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/
- Level: Introductory undergraduate.
- Materials: Lectures, assignments, and exams.
- Useful for: Learning programming and computational problem solving
  through Python.
- Access: Free; no registration.

### NUS — CS1101S
- URL: https://www.comp.nus.edu.sg/~cs1101s/
- Materials: Public course materials.
- Useful for: Programming methodology and foundational
  computational thinking.
- Access: Public materials are available; some assessments
  and student systems remain restricted.
- Selection: Inspect the linked course edition for its language,
  tools, prerequisites, and available exercises.

## Data structures and algorithms

### NUS — CS2040S
- URL: https://www.comp.nus.edu.sg/~stevenha/cs2040s.html
- Materials: Public course materials.
- Useful for: Studying data structures and algorithms.
- Access: Some assessments and student systems remain restricted.
- Selection: Verify prerequisites, implementation language,
  and availability of practice and solutions.

### Stanford Engineering Everywhere
- URL: https://see.stanford.edu/Course
- Materials: Archived programming and computer-science courses.
- Useful for: Discovering courses beyond introductory programming.
- Access: Free archived lectures and coursework;
  some exercises depend on unavailable Stanford systems.
- Selection: Link to the specific course in recommendations,
  and check whether its tools remain usable.

## Logic, formal verification, and programming languages

### University of Pennsylvania — Software Foundations
- URL: https://softwarefoundations.cis.upenn.edu/
- Materials: Online textbooks and exercises, including
  Logical Foundations and Programming Language Foundations.
- Useful for: Machine-checked proofs, formal verification,
  and programming-language theory.
- Access: Free; no enrollment.
- Selection: Check the chosen volume's prerequisites
  and required proof-assistant version.

## Data-oriented programming

### Johns Hopkins — R Programming for Data Science
- URL: https://bookdown.org/rdpeng/rprogdatascience/
- Materials: Online textbook.
- Useful for: R programming in a data-science context.
- Access: Freely readable.

### Berkeley — Open Textbooks
- URL: https://cdss.berkeley.edu/textbooks
- Materials: Online textbooks, including Data 8 and Data 100.
- Useful for: Programming applied to data analysis.
- Access: Freely readable.
- Scope: Combines computing with statistics;
  not a substitute for a general programming curriculum.
- Selection: Inspect individual books for prerequisites
  and the availability of executable exercises.

## Information retrieval

### NUS — CS3245

- Materials: Public course materials.
- Useful for: Studying information retrieval.
